# Snake, Water, Gun

A small command-line Python learning exercise. Despite the repository name, this project is not
about partial differential equations; it implements the Snake, Water, Gun game (a variant of Rock,
Paper, Scissors).

## Run

```bash
python main.py
```

Enter `s`, `w`, or `g` when prompted. Invalid input is rejected and you can try again.

## Test

```bash
python -m unittest discover -s tests -v
```
